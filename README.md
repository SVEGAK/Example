# Пример работы с GitHub-репозиторием
## *Основные команды Git bash:*

*Инициализировать Git репозиторий*
```
git init
``` 
*закрепить за папкой проекта репозиторий на GitHub*
```
git remote add origin <URL>.git
``` 

*Подтянуть изменения репозитория с GitHub*
```
git pull origin main
``` 
*Создание ветки, перейти в ветку и обе команды вместе*
```
git branch <имя ветки>
git checkout <имя ветки>
git chechkout -b <имя ветки>
```
*Переименовать ветку*
```
git branch -m <имя ветки>
```

## *Подготовка к коммитту*

*Посмотреть статус файлов ветки*
```
git status
```

*Добавить все файлы в коммит, также можно добавлять выборочно заменяя точку на имя файла*
```
git add . 
git add <имя файла>
```
*Убрать файл/файлы из коммита*
```
git reset . 
git reset <имя файла>
```
*Сохранить коммит* | **-m - флаг "message"**
``` 
git commit -m "что сделано?" 
``` 
*отправить имеющиеся сохранения на GitHub в ветку <имя ветки>*
``` 
git push origin <имя ветки>
```                              

## Дополнительные команды которые могут иногда пригодиться:
если git на устройстве настраивается впервые, появится предупреждение и потребуются команды:
```
git config --global user.name "Имя Ф."
git config --global user.mail "email@mail.ru"
```
*Скачивание уже существующего репозитория с гитхаб*
```
git clone <URL>.git
cd <имя репозитория>
```
